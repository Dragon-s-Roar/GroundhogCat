📌 一、软件简介

土拨猫是一款轻量级的表单辅助工具，主要解决「反复填写相同内容」
的痛点。你可以预先建好表单模板，然后一键复制任意字段内容，
无需手动选中复制。

核心功能：
  · 自由增删表单字段
  · 一键复制任意字段内容
  · 支持撤销操作（可回退多步）
  · 快速搜索定位字段
  · 自动保存数据到浏览器
  · 导出/导入数据备份


📌 二、如何获取和打开软件

1. 你收到的文件是一个 HTML 文件（如：土拨猫.html）

2. 双击该文件，系统会自动用浏览器打开（推荐 Chrome / Edge）

3. 打开后即可开始使用，无需安装任何软件

⚠️ 注意：请确保使用现代浏览器（Chrome 73+、Edge 79+、
Firefox 67+ 或 Safari 13+），以获得最佳体验。


📌 三、主界面说明

软件界面主要分为三个区域：顶部标题栏、中间内容区、右侧侧边栏。

【顶部标题栏】
位于页面最上方，左侧显示软件名称「🐱 土拨猫 - 智能表单填写助手」，
右侧显示历史记录步数（如「📌 3 / 10 步」），方便你了解当前
可撤销的步数。

【功能说明栏】
位于标题栏下方，用一行文字简要列出了软件的核心功能：
一键复制、支持撤销、快速检索、输入框自适应、可保存/导入、
修改序号调整位置。

【中间内容区】
占据页面大部分区域，用于展示和管理所有表单字段。

每个字段卡片包含：
  · 左侧：序号区域。包含当前序号数字、序号输入框（可修改）、
    「↑」「↓」两个微调按钮（分别对应序号-1和+1）。
  · 中间上方：标签名输入框。点击可修改字段名称。
  · 中间上方右侧：字符计数，显示当前内容的字符数。
  · 中间下方：内容输入框（多行文本框）。可输入任意长度的文本，
    输入框会根据内容自动调整高度。
  · 右侧：「📄」复制按钮。点击即可将该字段的内容复制到剪贴板。
  · 右上角：「✕」删除按钮。点击可删除该字段。

【左侧侧边栏】
固定在页面右侧中间位置，滚动页面时会跟随移动，始终可见。

侧边栏包含：
  · 品牌标识：「🐱 土拨猫」
  · 搜索框：输入关键词可快速筛选字段，右侧显示匹配数量。
  · 「↩️ 返回上一步」按钮：撤销上一次操作。
  · 「➕ 增加字段」按钮：在列表底部添加一个新字段。
  · 分割线
  · 「💾 保存到文件」按钮：将当前所有数据导出为 JSON 文件。
  · 「📂 导入文件」按钮：从 JSON 文件恢复数据。
  · 分割线
  · 「🗑️ 清空所有」按钮：删除所有字段（操作不可撤销）。
  · 底部：版本号信息。


📌 四、详细使用方法

【4.1 创建和编辑字段】

1. 点击「➕ 增加字段」按钮，在列表底部会出现一个新的空白字段

2. 每个字段由三部分组成：
   · 左侧：序号（可修改调整位置）
   · 中间上方：标签名（如「姓名」「邮箱」）
   · 中间下方：内容输入框（填写具体内容）

3. 修改标签名：直接点击标签名输入框，输入你想要的名字

4. 修改内容：直接在内容输入框中填写或粘贴内容

5. 删除字段：点击字段右上角的「✕」按钮

💡 内容输入框会自动根据内容长短调整高度，无需手动拉伸。


【4.2 一键复制内容】

1. 找到你想要复制内容的字段

2. 点击该字段右侧的「📄」复制按钮

3. 按钮会短暂变为绿色「✅」并弹出提示「已复制到剪贴板」

4. 切换到目标位置（如另一个表单、Word、Excel 等），使用 Ctrl+V
   （Mac 为 Command+V）粘贴即可

💡 复制的文本会保留换行和格式，适合复制地址、备注等多行内容。


【4.3 调整字段顺序】

方式一：修改序号
  1. 在字段左侧的序号输入框中直接输入目标序号（如把 6 改成 2）
  2. 按 Enter 键或点击页面其他地方，字段会自动移动到目标位置
  3. 其他字段的序号会自动顺延

方式二：点击箭头微调
  1. 点击字段左侧的「↑」按钮：序号 -1（字段向上移动一位）
  2. 点击字段左侧的「↓」按钮：序号 +1（字段向下移动一位）

💡 输入序号时，可以输入任意数字，系统会自动修正边界值
   （最小为 1，最大为当前字段总数）。


【4.4 撤销操作】

1. 每次修改（增删字段、修改内容、调整顺序等）都会被自动记录

2. 点击侧边栏的「↩️ 返回上一步」按钮，可回到上一步操作前的状态

3. 右上角会显示「📌 当前步数 / 总步数」，方便你了解历史记录

4. 最多可撤销 50 步

💡 撤销后如果做了新的修改，后面的历史记录会被自动覆盖
   （和大多数软件的行为一致）。


【4.5 搜索定位字段】

1. 在侧边栏的搜索框中输入标签名的关键词（如「姓名」）

2. 匹配的字段会高亮显示（蓝色边框和背景），不匹配的字段会被隐藏

3. 页面会自动滚动到第一个匹配的字段，并有脉冲动画提示

4. 匹配数量会显示在搜索框右侧

5. 点击搜索框右侧的「✕」按钮可一键清空搜索

💡 搜索时匹配的字段下方会显示高亮后的标签名，
   方便你确认匹配结果。


📌 五、数据保存方法

【5.1 自动保存（推荐）】

软件会自动将你所有的数据保存在浏览器的本地存储中。
关闭页面或浏览器后，下次打开时会自动恢复，无需手动操作。

⚠️ 注意：
   · 清除浏览器缓存/历史记录时，可能会删除本地存储的数据
   · 更换电脑或浏览器后，数据不会自动迁移
   · 建议定期手动备份（见下文「导出数据」）


【5.2 手动保存到文件（导出）】

1. 点击侧边栏的「💾 保存到文件」按钮

2. 浏览器会自动下载一个 JSON 文件
   （文件名格式：表单数据_20260805_1430.json）

3. 将该文件保存到你的电脑硬盘、云盘或 U 盘中

💡 建议：定期导出备份，以防浏览器数据丢失。


【5.3 从文件恢复（导入）】

1. 点击侧边栏的「📂 导入文件」按钮

2. 选择你之前导出的 JSON 文件

3. 确认导入后，当前数据会被替换为文件中的数据

⚠️ 注意：导入会覆盖当前所有数据，请确保已备份当前数据。


【5.4 清空所有数据】

1. 点击侧边栏的「🗑️ 清空所有」按钮

2. 确认后，所有字段将被删除

⚠️ 注意：此操作不可撤销！请确保已导出备份数据。


📌 六、常见问题（FAQ）

Q1：软件需要联网吗？
A1：不需要。软件在浏览器中纯本地运行，所有数据只保存在你的
    电脑上，不会上传到任何服务器。

Q2：换了一台电脑，数据还能继续用吗？
A2：可以。将导出的 JSON 文件拷贝到新电脑，使用「导入文件」
    功能即可恢复数据。

Q3：软件是免费的吗？
A3：是的，完全免费，没有任何功能限制。

Q4：最多可以添加多少个字段？
A4：没有限制，你可以根据需要任意添加。

Q5：软件会收集我的数据吗？
A5：不会。所有数据只保存在你的电脑本地，没有任何网络请求。

Q6：能用在手机上吗？
A6：可以。在手机浏览器中打开 HTML 文件即可使用，界面会自动
    适配移动端。但复制操作在手机上可能不如电脑方便。
